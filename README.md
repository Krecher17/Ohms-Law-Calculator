# Ohm's Law Calculator

A small Python program that finds voltage, current, resistance or power from the other two values.

## Formulas

- V = I x R
- I = V / R
- R = V / I
- P = V x I

## Run it

You need Python 3 installed.

```
python ohms_law.py
```

Pick what you want to find, then enter the two values it asks for.

## Run the tests

```
python -m unittest
```
